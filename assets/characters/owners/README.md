# 사장님 기본 리소스 — 확정 9종

`setting/assets/art/characters/owners-v2/`에 보관된 확정 PNG의 동일한 사본이다. 이 문서의 경로는 프로젝트 루트 기준이다.

- 사람: `human-male-idle.png`, `human-female-idle.png`
- 고양이: `cat-ginger-idle.png`, `cat-black-idle.png`, `cat-white-gray-idle.png`
- 여우: `fox-orange-idle.png`, `fox-white-idle.png`
- 토끼: `rabbit-white-idle.png`, `rabbit-light-brown-idle.png`

회색 토끼는 제외한다. 캐릭터별 원본 체형과 토끼의 수정된 눈매를 유지한다. 향후 스킨 작업은 `setting/GAME_ART_RULES.md`를 따른다.

모두 1254×1254 투명 PNG의 한 방향 기본 대기 이미지다. 규격은 `image-metadata.json`에 기록했다. 걷기 애니메이션·엔진 표시 크기·발 기준점은 후속 작업이며 현재 로그인 장면에는 배치하지 않았다.
