# 공통 모달과 박스 스타일

모든 게임 내 모달은 `TeaModal`을 사용한다. 로그인 패널과 모달은 `styles/tea_panel.tres`를 함께 참조한다. 색·테두리·둥글기·여백을 변경할 때는 이 공통 리소스를 수정한다.

```gdscript
var notice := TeaModal.new()
add_child(notice)
notice.show_preparation("카카오 로그인을 준비하고 있어요.")
```

`confirmed`는 확인 버튼 선택 시, `dismissed`는 모달이 닫힐 때 발생한다. `ui_cancel`도 닫기로 처리한다. 기본 컴포넌트는 단일 확인 안내용이며, 선택·입력 모달을 추가할 때도 이 컴포넌트를 확장하고 같은 박스 스타일을 유지한다. 닫기로 실제 게임 작업을 확정하지 말고 필요한 작업은 `confirmed`에 연결한다.

개발 준비 안내는 `show_preparation(앞부분 설명)`을 사용한다. 끝에는 공통 상수 `PREPARATION_CLOSING`의 “짠, 하고 인사드릴게요. 조금만 기다려 주세요!”를 붙이고, 응답 버튼은 “기다릴게요”로 표시한다. 기능마다 마지막 문장을 따로 만들지 않는다. 일반 오류·실제 로딩에는 이 개발 준비 안내를 사용하지 않는다.

화면 중앙 배치·배경 입력 차단·키보드 포커스 제한·닫은 후 포커스 복원을 포함한다. 향후 플레이 입력에서도 UI 입력 처리 여부를 존중하고 모달 뒤에서 행동하지 않게 한다.

문구는 짧고 다정한 해요체를 사용한다. 사용자가 대답하듯 “기다릴게요”, “좋아요”, “둘러볼게요”, “다시 해볼게요”로 쓰고, 문구만 읽어도 버튼의 행동을 알 수 있게 한다. 작업규칙 본문은 `setting/AGENTS.md`, 기획·아트 문서는 `setting/GAME_DESIGN.md`, `setting/GAME_ART_RULES.md`에 있다(프로젝트 루트 기준).
